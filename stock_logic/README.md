# 📈 LLM과 뉴스 분석 기반 주식 자동화 시스템 (Stock Automation using LLM + News Sentiment)

본 프로젝트는 LLM, 실시간 뉴스, 재무 데이터를 기반으로 한 **AI 기반 주식 자동 매매 분석 시스템**입니다. 투자자의 감정 대신 데이터와 논리에 기반한 매수/매도 결정을 지원합니다.

---

## 🧠 프로젝트 개요

이 프로젝트의 목표는 다음 요소들을 결합하여 **자동화된 주식 투자 판단을 지원**하는 것입니다:

- 📊 `yfinance`를 통한 과거 주가 데이터 수집  
- 🧠 OpenAI GPT 기반 뉴스 감성 분석  
- 🔎 Google Search API를 통한 실시간 뉴스 수집  
- 🤖 뉴스 기반 매수 / 매도 판단 로직 적용

---

## 🧩 시스템 구조

[ yfinance ] → 과거 주가 수집
↓
[ Google Search ] → 종목 관련 실시간 뉴스 수집
↓
[ OpenAI GPT API ] → 뉴스 감성 분석 (긍정 / 중립 / 부정)
↓
[ Decision Engine ] → 매수 / 매도 판단 출력


---

## ⚙️ 기능 요약

- 실시간 종목의 주가 및 재무 데이터 수집  
- 뉴스 기사 제목 및 내용 요약 수집  
- LLM을 통한 뉴스 감성 분석  
- 종합된 감성 점수 기반 매수 / 매도 신호 출력

## 📈 매수 / 매도 로직

### ✅ 초기 매수 조건
- 종가가 매수 구간 안에 들어오고  
- 포트폴리오 투자금이 60% 미만일 때  
- 해당 종목을 아직 보유하고 있지 않을 때

### 🔁 물타기(DCA) 조건

| 주가 하락폭 | 매수 비중 증가 | 횟수 제한 |
|-------------|----------------|-----------|
| -5% | +20% 추가 매수 | 1회 |
| -10% | +20% 추가 매수 | 2회 |
| -15% | +20% 추가 매수 | 3회 |
| -20% | 추가 매수 금지 | STOP |

### 📤 매도 조건
- 목표가 이상 도달 시 전량 매도  
- 손절가 하회 시 전량 매도 (-15% 기준)
